Demo video — shot-by-shot script

Le déroulé exact de la vidéo de soumission (Wildcard — Future of Work). Voix off en anglais (prête à lire), didascalies en français. L'arc suit les 4 verbes du thème : Plan · Coordinate · Decide · Execute, et couvre les 5 critères du jury.

✅ Problem (shot 1) ✅ Target users (shot 2) ✅ How the AI works (shots 3-4) ✅ Working demo (shots 3-6) ✅ Impact (shot 7) ✅ Best Use of Technology — Bob via MCP (shot 6)
Avant de tourner — préparation

Setup (5 min, une seule fois)

  1. État de démo propre : bash scripts/demo-behind.sh → te met en JB en retard sur main (Léa a fusionné), GenApp + CardDemo prêts.
  2. Navigateur : plein écran, 1920×1080 (ou 1440×900), masquer favoris/onglets. Charger http://127.0.0.1:8000 puis Cmd+Shift+R (purge cache).
  3. Identité : pastille haut-droite → nom JB, rôle Développeur.
  4. ⚠ Pré-chauffer l'agent : pose UNE question bidon à l'agent (ex. « what does LGIPOL01 do? ») avant de tourner, pour charger le modèle Granite → la vraie prise sera plus rapide.
  5. IBM Bob (2e fenêtre, VS Code) : serveur MCP cobol-explorer connecté (voir .bob/mcp.json) — pour le shot 6.
  6. Audio : narration en anglais, micro propre. Durée cible < 3:00 (couperet).

SHOT 30:2837 sAgent
DECIDE — the grounded agent
À l'écran
Panneau Agent à droite ; le graphe au centre.
Action
Tape What does program LGIPOL01 do? → Entrée. Le graphe grise puis s'illumine au fil du raisonnement ; la trace se déroule ; la réponse arrive avec citations fichier:ligne cliquables + badge « ✓ sources vérifiées ». Clique une citation → le code s'ouvre à la ligne exacte.
🎙 Voice-over
"Ask in plain English. The agent reasons over a live dependency graph — watch it light up — and every claim is tied to an exact source line, and re-verified. No hallucination: click a citation, and you land right on the code."
NOTELatence ~30-40 s : PRÉ-CHAUFFER avant (setup §4). Si encore lent : enregistre la question à part et coupe l'attente au montage. Le graphe qui s'illumine + les citations vérifiées = le cœur « grounded ».
SHOT 41:0530 sGraphe
PLAN — instant impact analysis
À l'écran
Onglet Graphe.
Action
⌘P → tape LGPOLICY → Entrée. Puis carte du graphe → « Voir l'impact d'un changement » → 11 nœuds rouges s'allument + les chaînes SDAILYPOL · SPOLRPT.

SHOT 51:3537 sModifs
COORDINATE + EXECUTE — governed change
À l'écran
Panneau Modifs, version « Hausse plafond moteur (JB) » sélectionnée.
Action
Montre « ⚠ en retard de 2 commits sur main » (Léa a fusionné). Clique « ↓ Importer main » → import propre → « ✓ à jour avec main ». Puis « Fusionner » → le merge-gate confirme l'impact → « Confirmer ».
🎙 Voice-over
"Changes live in isolated git branches. My teammate merged first, so I'm behind — and the system won't let me overwrite her work. I import, then merge mine, behind a confirmation gate and a tamper-proof audit trail. Two people, the same program, zero collisions."
NOTELe moat collaboration/gouvernance que PERSONNE d'autre n'a. Enchaîne vite : retard → import → merge-gate → confirmé.

Avant d'exporter

Pré-flight vidéo

  • Durée < 3:00 (couperet strict). Viser 2:45-2:55.
  • Narration en anglais, claire, sans lecture robotique. Sous-titres = bonus.
  • Latence agent coupée au montage (shot 3) — jamais 30 s d'écran figé.
  • Bob→graph_lookup visible (shot 6) — la preuve la plus forte, ne pas la rater.
  • Résolution 1080p, curseur visible, transitions nettes entre plans.
  • Upload public (YouTube non-listé / Loom), lien testé en navigation privée, placé en tête du README.
  • Pas de secret watsonx / d'email perso à l'écran.
